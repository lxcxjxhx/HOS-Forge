# HOS-Forge

HOS-Forge: AI Native Cyber Security IDE — 基于 OpenHands 的 AI 原生网络安全 IDE

## Overview

HOS-Forge is an advanced AI-powered cybersecurity development environment that extends OpenHands with specialized security tools, vulnerability analysis, and automated penetration testing capabilities.

## Features

- AI-driven security analysis
- Automated vulnerability detection
- Penetration testing automation
- Security code review
- Threat modeling assistance

## Installation

```bash
pip install hos-forge
```

## Usage

```bash
hos-mcp --help
hos-dashboard --help
hos-report --help
```
